TripAddicts

Plan smarter. Travel better. Explore more.

TripAddicts is an all-in-one travel planning app that helps you discover destinations, generate AI-powered itineraries, track weather, estimate travel costs, and manage group trips — all from a single platform.

✨ Features
🧠 AI Itinerary Generator

Create smart, day-wise travel plans based on your:

Destination 📍
Budget 💸
Trip duration 🗓️
🗺️ Interactive Maps
Visualize destinations and routes
Calculate distance from your current location
Explore places dynamically
🌦️ Weather-Based Discovery
Find destinations based on current weather
Plan trips according to ideal conditions
💰 Travel Cost Estimation
Compare travel costs via:
🚌 Bus
🚆 Train
✈️ Flight
🚖 Cab
Helps you plan within budget
👥 Group Expense Splitter
Easily split trip expenses with friends
Track who owes what
📸 Dynamic Destination Content
Beautiful destination images powered by Unsplash
🛠️ Tech Stack
Layer	Technology
Frontend	React (Vite), Tailwind CSS
Backend	Node.js, Express
Database	MongoDB
Maps	Leaflet
APIs	Gemini AI, Unsplash
🚀 Getting Started
📌 Prerequisites
Node.js 20+
⚙️ Installation
npm install
🔐 Environment Variables

Create a .env file based on .env.example and add:

GEMINI_API_KEY=your_key_here
UNSPLASH_ACCESS_KEY=your_key_here
MONGODB_URI=your_mongo_uri
JWT_SECRET=your_secret
▶️ Run Locally
npm run dev
📦 Production Build
npm run build
npm start
